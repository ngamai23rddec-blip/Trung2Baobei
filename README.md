# Hán ngữ của tôi
Cách dùng: giải nén, mở `index.html` bằng Chrome/Edge (giữ `data.js` cùng thư mục).
- 138 từ lấy nguyên từ file Word (Bài 9-15), không thêm/đổi nghĩa.
- Tiến độ lưu trong trình duyệt (localStorage), không mất khi refresh. Đổi trình duyệt/máy sẽ là dữ liệu mới.
- Phát âm dùng giọng Mandarin có sẵn của thiết bị (Chrome/Edge/Android/iOS thường có zh-CN).
- Nhập thêm .docx: tab Từ vựng -> Nhập .docx (cần internet lần đầu để nạp bộ đọc Word). Từ trùng sẽ bị bỏ qua.
- Xuất dữ liệu: CSV (mở bằng Excel).
- Luyện tập: có thêm dạng trắc nghiệm Hanzi→Pinyin và Pinyin→Hanzi (đáp án gần giống nhau); ô "Số câu" để trống = tất cả câu của bài.

## Cập nhật giao diện (Trung 2 BaoBei)
- Trang chủ + sidebar xanh lá, bo tròn, font Baloo 2 / Nunito (cần internet lần đầu để nạp font; offline vẫn chạy với font dự phòng).
- Thẻ ghi nhớ: chọn bộ thẻ theo Loại / Trạng thái-Điểm / Chủ đề (bài), lật thẻ 3D, chấm Lại nào / Khó nhằn / Ổn áp / Dễ ợt. Phím tắt: Space = lật, 1-4 = chấm điểm.
